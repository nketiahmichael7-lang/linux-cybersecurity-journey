# Lesson 3 - Linux Files and Directories

## Commands Learned

- `mkdir` - creates a directory
- `touch` - creates an empty file
- `cp` - copies files or directories
- `mv` - moves or renames files and directories

## Practical Exercises

I practiced creating directories and files and then moving, copying, and renaming them.

Examples:

```bash
mkdir auth
touch login.log
cp network.txt reports/
mv security.txt evidence/
mv notes.txt linux_notes.txt
