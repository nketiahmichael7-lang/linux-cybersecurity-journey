# Lesson 2 - Linux Filesystem & Navigation

## Commands Learned

- `pwd` - shows the current working directory
- `ls` - lists files and directories
- `cd` - changes the current directory
- `cd ..` - moves up one directory level

## Paths

### Absolute Path

An absolute path starts from the root directory `/` and provides the complete location of a file or directory.

Example:

`/home/michael/linux-cybersecurity-journey`

### Relative Path

A relative path describes a location starting from the current directory.

Example:

`01-linux-fundamentals`

## Key Takeaway

Linux uses a hierarchical filesystem. Understanding paths and directory navigation is important when investigating files, locating system resources, and working with Linux security tools.
